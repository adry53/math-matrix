# Math Matrix 🧮

Учебный проект с реализацией базовых алгоритмов линейной алгебры на Python.

## 📦 Содержание
- `gauss.py` — Метод Гаусса для решения систем линейных уравнений
- `invers.py` — Нахождение обратной матрицы
- `grammer.py` — Правило Крамера

## 🚀 Быстрый старт

Убедитесь, что установлен Python 3.7+.

```bash
# Склонировать репозиторий
git clone https://github.com/adry53/math-matrix.git

# Перейти в папку проекта
cd math-matrix

# Запустить пример (допустим, метод Гаусса)
python gauss.py
