# Math Matrix 🧮

An educational project implementing basic linear algebra algorithms in Python.

## 📦 Contents
- `gauss.py` — Gaussian elimination for solving systems of linear equations
- `invers.py` — Finding the inverse of a matrix
- `grammer.py` — Cramer's rule

## 🚀 Quick Start

Make sure you have Python 3.7+ installed.

```bash
# Clone the repository
git clone https://github.com/adry53/math-matrix.git

# Navigate to the project folder
cd math-matrix

# Run an example (e.g., Gaussian elimination)
python gauss.py
